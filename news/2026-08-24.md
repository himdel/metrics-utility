# Newsletter 2026-08-24

## Changes

### ansible/metrics-utility

- Switch tests and perf tools to the `unified_jobs_dashboard` collector, parametrizing shared integration tests over both the CLI and metrics-service collector variants (ansible/metrics-utility#538)
- Support implicit S3 credentials: access/secret key env vars are now optional so boto3's default chain (IRSA, instance profiles) can resolve; half-configured key pairs are rejected and credentials are verified eagerly for an actionable early error (ansible/metrics-utility#547)
- Bump Django to 5.2.17 for CVE-2026-15307 (ansible/metrics-utility#541)
- Relax the setuptools runtime pin `==80.9.0` -> `>=80.9.0`, which collided with Django's `setuptools>=83` build-system requirement in hermetic builds (ansible/metrics-utility#550)
- Loosen runtime dependency pins to compatible-release `~=major.minor` ranges so exact pins stop fighting the parent's combined `uv pip compile` when the library is vendored under metrics-service (ansible/metrics-utility#552)

### ansible/metrics-service

- Remove `core.User` from the RBAC model registry to prevent a `shared.user` DABContentType that crashed gateway's role_definitions with a LookupError; includes a cleanup migration (ansible/metrics-service#401)
- Authenticate the service metadata probe without an RBAC claims fetch (`ServiceJWTAuthenticationNoRBAC`), fixing a circular service_id-NULL deadlock in gateway's populate_service_id probe (ansible/metrics-service#405)
- Rework the openapi spec sync workflow to sync per stable branch: one PR per target branch via force-push + `gh pr list` reuse, new `OPENAPI_SPEC_PR_REVIEW_TEAM` secret (ansible/metrics-service#403)
- Disable Mintmaker (Renovate Tekton `postUpgradeTasks`) so the pipeline-migration-tool can run (ansible/metrics-service#402)
- Bump Django to 5.2.17 for CVE-2026-15307 (ansible/metrics-service#404)
- Loosen runtime dependency pins (django/urllib3/pyjwt `==` -> `~=`) plus a Dependabot semver-major ignore rule, mirroring the metrics-utility change (ansible/metrics-service#406)
- Monthly-batch dependency group bump, routine GitHub Actions version updates (ansible/metrics-service#395)

### ansible/awx (database schema)

- No schema changes affect any of our dependent collector tables this week. Migration 0208 is a data-only `RunPython` backfill of missing `Platform Auditor` role assignments for legacy `system_auditor` members (ansible/awx#16582); the DAB RBAC activity-stream change only writes additional `main_activitystream` rows (ansible/awx#16584); and ansible/awx#16597 reverts prior org-member-role work with no migration. All changes are confined to DAB RBAC tables and `main_activitystream` - no DDL, no columns/tables/indexes altered.
