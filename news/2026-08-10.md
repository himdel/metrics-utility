# Newsletter 2026-08-10

## Changes

### ansible/metrics-utility

- Exclude workflow child jobs from dashboard job collection -- child jobs have NULL `launched_by_id`, causing mismatch between totals and Top 5 Users chart (ansible/metrics-utility#525)
- Accept unknown kwargs in `anonymize_rollups()` for forwards compatibility with newer metrics-service versions (ansible/metrics-utility#513)
- Parameterize host_metric SQL and switch to multi-column keyset pagination -- replaces f-string interpolation with parameterized queries, fixes CONCAT-based pagination (ansible/metrics-utility#530)
- Handle NULL host_id in job_host_summary SQL collector (ansible/metrics-utility#532), then immediately reverted (ansible/metrics-utility#533) -- name-based fallback JOIN had many-to-many match risk
- Test event collection tooling -- comprehensive AWX test playbook suite for end-to-end event collection testing (ansible/metrics-utility#501)
- Group dependabot updates into single monthly PRs (ansible/metrics-utility#512)

### ansible/metrics-service

- Compute dashboard card counts from raw job queryset instead of filtered aggregated queryset -- fixes mismatch between card counts and job listing when orphan jobs exist (ansible/metrics-service#386)
- Exclude workflow child jobs from hourly dashboard sync hook, companion to ansible/metrics-utility#525 (ansible/metrics-service#388)
- Fix AWX label query: initial GROUP BY dedup (ansible/metrics-service#387) was reverted (ansible/metrics-service#390) because it collapsed org-scoped labels with the same name. Replaced with org-aware disambiguation that appends org name only when label names are ambiguous (ansible/metrics-service#389)
- Task state machine formally documented with Mermaid diagram and invariants (ansible/metrics-service#356)
- Group dependabot updates into single monthly PRs (ansible/metrics-service#376)

### ansible/awx (database schema)

- No schema changes this period. One commit processed ([AAP-82668] skip old RBAC sync on cascade-deleted assignments, ansible/awx#16559) was a Python-only signal handler optimization with no migration or model field changes.
