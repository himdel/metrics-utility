# Newsletter 2026-11-16

## Changes

### ansible/metrics-utility

- `unified_jobs_dashboard` takes optional `after_id` / `batch_size` for ID-ordered cursor pagination (`ansible/metrics-utility#640`, AAP-102065). Default output is unchanged. This prepares AAP-101700: the metrics-service backfill and update task will switch from `dashboard_jobs` to `unified_jobs_dashboard`, so all three paths into `JobData` use one job definition. This includes sync and workflow jobs, which `dashboard_jobs` never returned. Both values are validated before they go into the SQL (numpy ints accepted, bools/floats/strings rejected).
- Dropped the unused `kubernetes` runtime dependency, left over since `ansible/metrics-utility#198` moved `total_workers_vcpu` to Prometheus (`ansible/metrics-utility#636`). 12 packages leave the lockfile, including `oauthlib` and the `aiohttp` stack. Downstream images can drop their `oauthlib>=4.0.0` build constraint.

### ansible/metrics-service

- django-ansible-base bumped to 2026.11.3 (git rev `bf4d98d`) to get `pyasn1` 0.6.5 for CVE-2026-119194/119195/119196 (`ansible/metrics-service#542`). The CVE is fixed through DAB rather than a direct `pyasn1` pin. Backports to 2.6 and 2.7 are to follow.
- Cleanup of duplicated code (`ansible/metrics-service#540`): the two dashboard backfill `batch_size` validators are now one `_backfill_batch_size(default, kwargs)`, and `get_cmd` / `_times` / `_create_task_safely` live in `tests/test_utils.py`. No behaviour change.
- aap-api-tests Docker digest updates (`ansible/metrics-service#538`, `ansible/metrics-service#541`).

## Inconsistencies

- Until `ansible/metrics-service#543` lands, hourly-synced and backfilled `JobData` rows still come from different job sets. The backfill (`dashboard_jobs`) excludes sync and workflow jobs that the hourly path (`unified_jobs_dashboard`) includes.
- The two paginated dashboard collectors validate differently. `dashboard_jobs` raises `ValueError` when only one of `after_id` / `batch_size` is given, while `unified_jobs_dashboard` (`ansible/metrics-utility#640`) accepts either one alone.
