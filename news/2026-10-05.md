# Newsletter 2026-10-05

Covers 2026-09-29 .. 2026-10-05 (0 metrics-utility commits, 6 metrics-service, 0 AWX schema-relevant).

## Changes

### ansible/metrics-service

**BYO-BI analytics collection and API (ANSTRAT-1587).**
`ansible/metrics-service#430` adds a new `apps.analytics` app. It stores raw collector output in a new append-only `AnalyticsPayload` table, so customers can feed it into their own BI tooling.
- API at `/api/v1/analytics/` (`/api/metrics/v1/analytics/` behind platform ingress), restricted to system admins and auditors. It has three parts:
  - a discovery root
  - paginated per-collector rows, filtered by `since`/`until` window overlap
  - `POST <collector>/collect/`, which returns 202 with a task URL (admins only, auditors cannot POST)
- Every enabled collector's raw output is now captured in `generic_collect_metrics`. 15 analytics-only collectors are registered with `persist_to_hourly=False`.
- New `collect_analytics_on_demand` task. `cleanup_metrics_data` gains `analytics_retention_days` (default 90).
- New docs: `docs/analytics.md`, `docs/ingress.md`. New `tools/seed-awx-demo.sql` seeds AWX demo data for exercising collectors locally.
- `ansible/metrics-service#458` - the analytics root gains a per-collector `last_collect` (latest `finished_at`, null if never collected).

**Gamification renamed to Leaderboard (XLAB).**
- `ansible/metrics-service#437` - breaking rename:
  - `SHOW_GAMIFICATION` / `show_gamification` -> `SHOW_LEADERBOARD` / `show_leaderboard` in `collection_status` GET/POST. Clients still sending the old key get a 400.
  - A reversible data migration renames the stored setting, so existing toggles survive.
  - The default flips from off to on.
  - The leaderboard endpoint now returns 404 "Leaderboard not enabled" when the flag is off.
  - `collection_status` also gains `last_sync` (last completed `sync_dashboard_job_records` run).
- `ansible/metrics-service#457` - Leaderboard `org_streak` is now the caller's own busiest organization rather than the busiest overall. Rows gain `user_organization`. `org_streak.organization` can now be null.

Other changes:
- `ansible/metrics-service#449` - PyJWT `~=2.13` -> `~=2.15` for CVE-2026-102273 (AAP-94862).
- `ansible/metrics-service#448` - aap-api-tests image digest bump.
