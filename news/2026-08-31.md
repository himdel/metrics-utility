# Newsletter 2026-08-31

## Changes

### ansible/metrics-utility

- Indirect managed nodes reached GA default-on. The `main_indirectmanagednodeaudit` collector is now default-enabled (ansible/metrics-utility#560), the indirect-node report sheets and report type default on with `METRICS_UTILITY_REPORT_TYPE` now defaulting to CCSPv2 (ansible/metrics-utility#559), and indirect nodes are folded into the "Usage by collections" sheet by exploding each audit row's FQCN list into per-collection rows (ansible/metrics-utility#558). Disable paths are preserved.
- host_metric SQL moved out of `ExtractorControllerDB` into a `main_hostmetric` library collector, using a new generic `sql_keyset()` keyset-pagination method on the output adapters (ansible/metrics-utility#536).
- AWX schema dump fixture refreshed to add two DAB RBAC global-assignment partial unique indexes; inert for us (ansible/metrics-utility#535).
- Push-triggered downstream repo-sync workflow added, syncing to ansible-automation-platform via a scoped GitHub App token (ansible/metrics-utility#563).
- sqlparse bumped to >=0.6.0 for three CVEs (ansible/metrics-utility#564).

### ansible/metrics-service

- `INDIRECT_NODE_COLLECTION` feature flag flipped to default True for the AAP 2.7 GA — the collection-scheduling half of the same rollout as the metrics-utility collector work (ansible/metrics-service#413).
- Push-triggered downstream repo-sync workflow added, mirroring the metrics-utility one (ansible/metrics-service#416).
- sqlparse bumped to >=0.6.0 for the same CVEs (ansible/metrics-service#417).

### ansible/awx (database schema)

- `main_host` drops the `last_job_id` and `last_job_host_summary_id` FK columns (migration 0210); the serializer now derives them from `main_jobhostsummary` via `Host.latest_summary` (ansible/awx#16529). `main_host` is one of our collector-dependent tables.
- Migration graph re-parented for a 2.6 backport: `0206` re-parented onto `0203`, a new empty merge migration `0207_merge_0205_0206`, and `0207/0208` renumbered to `0208/0209` — no DDL (ansible/awx#16612).
- DAB RBAC queryset-pattern refactor (drops `ResourceMixin`, `access_qs`/`access_ids_qs`) and activity-stream format unification for role-assignment APIs — query/access-layer only, no schema change to any of our tables (ansible/awx#16118, ansible/awx#16616).

## Inconsistencies

- AWX `main_host` schema change to adapt to: the `last_job_id` and `last_job_host_summary_id` columns are dropped in AWX devel/2.7 (ansible/awx#16529), completing the earlier deprecation (ansible/awx#16332). Any collector still reading `main_host.last_job_id` (e.g. for a last-automation date) will break and must switch to deriving the latest job from `main_jobhostsummary` (join on `host_id`, take the latest row, read `job_id`).
