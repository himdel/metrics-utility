## Inconsistencies

- The indirect node collector went through three pipeline moves on the service side in one week: hourly -> snapshot (#331) -> daily (#332). This was driven by the library-side evolution: #464 briefly made it a snapshot collector, then #475 converted it to daily slicing, requiring the service to follow. The rapid churn suggests the library and service changes should be coordinated in the same PR cycle to avoid intermediate states.
- AWX has two open PRs proposing migration 0206 with different schemas (`jobhostsummary_host_id_idx` in ansible/awx#16530 and `remove_host_last_job_fields` in ansible/awx#16529). If both merge, one will need renumbering. The `remove_host_last_job_fields` PR drops `Host.last_job` and `Host.last_job_host_summary` FK fields -- our collectors don't use these fields, so no downstream impact expected.
