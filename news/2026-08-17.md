# Newsletter 2026-08-17

## Changes

### ansible/metrics-utility

- ansible/metrics-utility#511 (AAP-84017) — add a schema and validation script for the anonymized daily rollup Segment payload. TypedDict definitions in `anonymized_rollups/types.py` are now the single source of truth for the aap-metrics/Analytics contract; the OpenAPI schema is generated from those types via pydantic `TypeAdapter` (not hand-maintained), and a strict validation script (`extra='forbid'`) checks rollup JSON against them. pydantic/pyyaml added as dev-only deps.

### ansible/metrics-service

- ansible/metrics-service#394, ansible/metrics-service#396, ansible/metrics-service#397 — the `sync-openapi-specs` CI workflow was reworked across three PRs to match the handbook OpenAPI drift-detection standard: make the spectacular generator run headless (correct `DJANGO_SETTINGS_MODULE`, `METRICS_SERVICE_` dynaconf env vars, per-db SQLite overrides), conform to `aap-openapi-specs` conventions (flat-file output, versioned `stable-*` branch targeting, `diff -q` instead of `git diff`, handbook token/artifact/PR-template naming), and sign commits with the `aap-api-bot` GPG key for verified commits.
- ansible/metrics-service#399 (AAP-87800) — honor the `ANONYMIZED_DATA_COLLECTION` opt-out for Segment sends. Defense in depth: dynamically-created `send_anonymized_to_segment` tasks are tagged with `_feature_flag: ANONYMIZED_DATA_COLLECTION` so the scheduler respects opt-out, and a sender-side runtime guard skips transmission when the flag is disabled (covers pre-fix pending tasks and dispatcher paths that bypass scheduler registration).
- ansible/metrics-service#398 — add per-domain architecture docs under `docs/` (core/RBAC, task system, APScheduler, collectors, dashboard sync) with Mermaid diagrams; fixes stale references (`TaskChain`, signals-based task submission, `init-system-tasks` command name, `DASHBOARD_COLLECTION` default).

### ansible/awx (database schema)

- ansible/awx#16585 (AAP-87829) — make migration `0206_jobhostsummary_host_id_idx` idempotent. The `main_jobhostsumm_host_id_desc` index (host_id, id DESC) on `main_jobhostsummary` is now wrapped in `SeparateDatabaseAndState` with `CREATE INDEX IF NOT EXISTS`, so upgrades no longer fail with `relation already exists` when customers created the index manually on 2.6. Affects **main_jobhostsummary** (one of our collector tables) — index mechanics only, no column/type/constraint change. Forward-port of tower#7895.
- ansible/awx#16590 — RBAC cleanup no longer deletes JWT-managed roles (e.g. Platform Auditor) and cascade-deletes their assignments. Touches DAB RBAC tables only; none of our collector tables affected.
