# Newsletter 2026-06-22

## Changes

### ansible/metrics-utility

- Candlepin v2 billing integration with mTLS cert auth, `CandlepinStore` abstraction, and full test suite (ansible/metrics-utility#363)
- JSON schema validation tests and tarball validator tool for billing schemas (ansible/metrics-utility#428, ansible/metrics-utility#434)
- Schema-review CI workflow consolidated to `pull_request_target` for fork write permissions, plus stability improvements (ansible/metrics-utility#436, ansible/metrics-utility#438)
- HCC analytics reviewer auto-assignments removed, replaced with comment pings (ansible/metrics-utility#440)
- Schemas moved into `metrics_utility` package for pip installability; validator path fixed to match (ansible/metrics-utility#444, ansible/metrics-utility#447)
- Indirect managed nodes anonymized rollup collector added (ansible/metrics-utility#446)
- `cleanup_glob` refactored: empty dir removal, shared test helper extracted to util (ansible/metrics-utility#448)
- GitHub Actions pinned to commit SHAs with version comments (ansible/metrics-utility#449)

### ansible/metrics-service

- URL tests cleaned up: exception suppression removed, separate test URL config dropped in favor of Dynaconf `__` syntax (ansible/metrics-service#263)
- Framework alignment (AAP-69237): project code extracted from protected `settings.py` into `apps/settings` with post-hooks, `framework-validation` CI workflow re-added (ansible/metrics-service#267)
- Dead psycopg3 connection detection via `SELECT 1` probe before operations (ansible/metrics-service#273)
- Anonymize task: `SEGMENT_MAX_ATTEMPTS` removed (was misapplied), retry base delay changed from 10 to 8 min (coprime with 5-min task spacing to prevent collision patterns) (ansible/metrics-service#276)
- Stale advisory lock cleanup via `pg_terminate_backend` for locks held by dead PIDs (ansible/metrics-service#277)
- Task create fixed: argparse `None` was being passed as NULL description to DB (ansible/metrics-service#278)
- Renovate cron schedule fixed; CI check added to prevent wildcard `*` in cron minute field (ansible/metrics-service#281)
- Trends export test flake near midnight UTC fixed with frozen time (ansible/metrics-service#282)
- UV ecosystem added to dependabot config (ansible/metrics-service#284)
- Dependency bumps: ruff 0.15.18, pytest-asyncio 1.4.0, isort 8.0.1, django-prometheus 2.5.0, croniter 6.2.2, sonarqube-scan-action 8.2.0, codecov-action 7.0.0 (ansible/metrics-service#288-#294)
