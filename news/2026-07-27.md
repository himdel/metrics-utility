# Newsletter 2026-07-27

## Changes

### ansible/metrics-utility

- ansible/metrics-utility#492, ansible/metrics-utility#495 -- Schema nullability fixes: added nullable to `config-1.0` requested fields, then reverted `cluster_name` in `total_workers_vcpu-1.0` that was wrongly included
- ansible/metrics-utility#480 -- Events rollup reshaped from inferred task outcomes to direct event counters; new shared `event_types.py`, `ignore_errors` extraction from two JSON paths, `event_data_length` for perf modeling
- ansible/metrics-utility#496 -- Filter private collections from indirect nodes Segment payload; centralized `load_known_collections()` in helpers.py
- ansible/metrics-utility#488 -- Replaced MinIO with SeaweedFS for S3-compatible dev/CI storage: zero-setup, no init container, env-var config only
- ansible/metrics-utility#494 -- Jira PR link workflow ported from metrics-service Python implementation (append instead of overwrite)
- ansible/metrics-utility#487, ansible/metrics-utility#497, ansible/metrics-utility#499 -- AWX schema CI hardening: Python 3.14+ `backports-zstd` filter, `pg_dump` auth fix, validation + Slack notifications, dropped auto-PR creation
- ansible/metrics-utility#500 -- Added mock Segment server to `pytest-service` CI job

### ansible/metrics-service

- ansible/metrics-service#353 -- Fixed CSV export: cost rows were rendered as raw numbers instead of formatted currency strings
- ansible/metrics-service#357 -- Hardened DAB-provided views (activitystream, feature_flags, users) with class-attribute permission patching at app startup to restrict to platform auditor
- ansible/metrics-service#360 -- Expanded system task field protection: `name`, `status`, `task_data` now blocked for PATCH alongside existing protected fields
- ansible/metrics-service#361 -- Blocked `POST /organizations/` to prevent 500 from DAB `post_save` signal crash; endpoint now restricted to read-only
- ansible/metrics-service#359 -- Fixed Swagger schema URL and `feature_flags` redirect to include gateway service prefix
- ansible/metrics-service#358 -- Return 400 for query params containing null bytes (was causing unhandled PostgreSQL `DataError`)
- ansible/metrics-service#363 -- Enabled Controller retention for dashboard collection by default (`USE_CONTROLLER_RETENTION=True`)
- ansible/metrics-service#364 -- Fixed Prometheus metrics endpoint: dual URL registration (with and without trailing slash) to survive gateway round-trip
- ansible/metrics-service#365 -- `initial_resource_sync` now retries on failure with 60s backoff, 5 attempts (matching gateway's `populate_service_id` timing)
- ansible/metrics-service#366 -- Added `SEGMENT_URL` Dynaconf setting + mock Segment Go server for CI integration tests
- ansible/metrics-service#368, ansible/metrics-service#369 -- Pinned `pyasn1` to `~=0.6.4` (compatible release) to fix build breakage

### ansible/awx (database schema)

- ansible/awx#16552 -- Migration 0207: `skip_tags` column converted from `CharField(max_length=1024)` to `TextField` on `main_job` and `main_jobtemplate`. Drops the 1024-char CHECK constraint; values may now exceed 1024 characters. Both tables are in our dependent set.
- ansible/awx#16545 -- RBAC role definitions updated via `dab_post_migrate` signal (not a numbered migration) to add `member_organization` permission to Organization *Admin roles. No schema impact on dependent tables.
